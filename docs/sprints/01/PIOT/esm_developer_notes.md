## Требования
- Драйвер ККТ не ниже 10.10.8.24.
- ККТ зарегистрирована на ФФД 1.2, включён параметр «Торговля маркированными товарами».
- Перед обновлением ЛМ ЧЗ до 2.0 — обновить компоненты ЕСМ до v.1.6.
- Для ЛМ ЧЗ 2.0: ЕСМ >= 1.6, lm-controller >= 1.6.## Установка (дистрибутив `esmpack_linux64_<версия>.zip`)

1. Скопировать на кассу (WinSCP).
2. Подключиться по SSH (PuTTY).
3. Разархивировать: `unzip esmpack_linux64-<***>.zip`
4. Установить драйверы ККТ:
   ```
   cd DKKT
   unzip 10.10.<>-deb.zip
   sudo apt update && sudo apt install -yf ./*$(dpkg --print-architecture)*.deb
   ```
   (Если ошибка — `unzip 10.10.` + Tab, повторить.)
5. Установить ЕСМ:
   ```
   cd ..
   sudo apt install -yf ./esm_*$(dpkg --print-architecture).deb
   ```
6. Если ЛМ ЧЗ на этом же ПК — установить Контроллер ЛМ ЧЗ:
   ```
   sudo apt install -y ./esm-*$(dpkg --print-architecture).deb
   ```

## Настройка ЕСМ (при открытой смене!)

1. Тест драйвера ККТ: `fptr10_t` (или `Appmenu → Other → ATOL Fiscal Printer Test v.10`).
2. Подключиться к ККТ (COM/IP). Порт сервера GRPC: `4041`. Проверить связь.
3. Включить флаг «Включено».
4. Открыть смену: `Чек → Открыть смену`.
5. Запустить GUI ЕСМ: `esm-gui` (или `Appmenu → Other → ESP ESM Setting and Control`).
6. Нажать «Обновить список» — отобразятся данные ККТ.
7. Нажать «Зарегистрировать» в блоке «ЕСМ» — получится лицензия и id ГИС МТ.
8. Ожидаемые статусы:
   - ЕСМ лицензия: «Активна до [дата]»
   - ЛМ ЧЗ: «Готов к работе»
   - ГИС МТ: «Стабильно»
9. Настроить адрес ЛМ ЧЗ: `127.0.0.1` (локально) или IP сервера.
10. Адрес ГИС МТ: `https://ts-reg.crpt.ru:19100` (по умолчанию).

## Рекомендации по взаимодействию ПМСР с ТС ПИоТ (ЕСМ)

1. Использовать только ДККТ из состава дистрибутива ТС ПИоТ. Сторонние драйверы — нарушения.
2. ДККТ должен быть запущен всю смену: от старта фискальной смены (до первого документа) до её закрытия. Остановка в середине смены — разрыв аутентифицированного сеанса.
3. Проверять КМ последовательно: сначала ТС ПИоТ, потом ОИСМ. Параллельные/обратные вызовы увеличивают несвоевременные ответы.
4. Контроллер ЛМ ЧЗ — на том же ПК, где и ЛМ ЧЗ. Порт 50063 — не менять. Проверять логин/пароль ЛМ ЧЗ.
5. Использовать актуальные версии дистрибутивов.
6. Не блокировать адреса ЕСП и ЦРПТ в Firewall.

## Ошибки

| Ошибка | Рекомендация |
|---|---|
| 514: не получить ответ от ГИС МТ/ЛМ ЧЗ | Проверить ЛМ ЧЗ и Контроллер на одном ПК, порт 50063, логин/пароль, статус «Готов к работе». Онлайн: соединение по 4041, доступность ресурсов. |
| 403: нет активной лицензии | ДККТ остановился в середине смены — ЕСМ потерял доступ к ККТ. Запускать ДККТ при открытии смены. |
| 407: работа с маркированными товарами временно заблокирована | ФН занят. Повторить сканирование через 1–3 сек. Часто вызвано параллельной проверкой. |
| Ошибки регистрации ЕСМ | ККТ на ФФД 1.2, признак «Торговля маркированным товаром» включён, смена открыта (<24ч), лицензия ЕСП получена. Проверить https://stats.ao-esp.ru и https://api.ao-esp.ru. |
| 2015 / context deadline exceeded | Ошибка авторизации — проверить ЛКК ЕСП. Если только в GUI и проверки проходят — нормально. |
| 403, 408, 502, 927, 928 | Нормальное поведение — идти на другую CDN-площадку. Повторить через пару секунд. |
| 12029: REST request failed | Кассовая программа не установила связь с ЕСМ. Проверить: запущены ли службы ЕСМ, адрес/порт, антивирус/экран, не запускать КПО до полного старта ЕСМ. |
| ЕСМ не видит ККТ | Обновить ЕСМ и драйверы ККТ. Проверить прошивки/лицензии. Удалить ДККТ других производителей. |
| Долгая инициализация ЛМ ЧЗ | Инициализация только при связи с ГИС МТ. Обновить ЕСМ и lm-controller до >= 1.6.2.0. При застревании — сменить источник интернета. |
| Нет связи с ЛМ ЧЗ | Контроллер на одном ПК с ЛМ ЧЗ; службы esm-lm-controller, regime, yenisei запущены; порт 50063; логин/пароль совпадают. |
| tls: failed to verify certificate | Установить сертификаты `ca` и `gismt` из `%ProgramData%/ESP/ESM/um` в «Доверенные корневые центры сертификации». |
