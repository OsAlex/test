Контроллер ЛМ ЧЗ устанавливается на машину с ЛМ ЧЗ, установочный файл для контроллера ЛМ ЧЗ предоставляется ЕСП. 

## Установка ДККТ и ЕСМ 

Скачайте дистрибутив вида esmpack_linux64_<версия>.zip 

1.  Скопируйте файл на кассу, используя WinSCP или другим удобным способом. 

2.  Подключитесь к кассе по ssh, используя PuTTy или другим удобным способом. 

3.  Разархивируйте: 

```
unzip esmpack_linux64-<***>.zip
```

где, <***> – версия дистрибутива. 

4.  Выполните команды для установки драйверов ККТ, из директории, в которую загружены установочные пакеты: 

```
cd DKKT
unzip 10.10.<>-deb.zip
sudo apt update && sudo apt install -yf ./*$(dpkg --print-architecture)*.deb
```

Наименование архива может отличаться. Если при выводе команды возникает ошибка, введите unzip 10.10. и нажмите клавишу <Tab>. Выполните команду. 

5.  Выполните команды для установки ЕСМ, не выходя из директории установки драйверов ККТ: 

   - `cd ..` 

```
sudo apt install -yf ./esm_*$(dpkg --print-architecture).deb
```

6.  Если ЛМ ЧЗ установлен на этом же ПК, установите ЛМ Контроллер. Для этого выполните следующую команду: 

```
sudo apt install -y ./esm-*$(dpkg --print-architecture).deb
```

## Рекомендации по корректному взаимодействию ПМСР с ТС ПИоТ (ЕСМ) 

Соблюдение этих правил поможет вам в организации стабильной работы кассового узла в течение смены. 

### 1. Используйте ДККТ из состава дистрибутива ТС ПИоТ. 

Для взаимодействия с ККТ необходимо использовать Драйвер ККТ, поставляемый в составе дистрибутива ТС ПИоТ. 

- Дистрибутив доступен для скачивания в личном кабинете партнёра. 

- Использование сторонних драйверов ККТ приведет к нарушениям работы ТС ПИоТ 

- При выходе новых версий ТС ПИоТ ДККТ обновляется синхронно — всегда используйте версию из актуального дистрибутива. 

### 2. Держите ДККТ запущенным всю смену. 

Для корректного взаимодействия с ККТ экземпляр ДККТ должен быть запущен на протяжении всей рабочей смены. 

- Остановка ДККТ в середине смены приводит к разрыву аутентифицированного сеанса связи с ККТ и требует повторной инициализации канала. 

- Запуск ДККТ должен выполняться при старте фискальной смены (до первого фискального документа) и продолжаться до её закрытия. 

### 3. Соблюдайте последовательность проверки кодов маркировки. 

Для снижения числа ситуаций, когда ответ от ОИСМ не успевает вернуться до фискализации, рекомендуем выполнять проверку КМ последовательно. Как вариант: 

- Сначала — проверка через ТС ПИоТ. 

- Только после получения ответа от ТС ПИоТ — проверка в ОИСМ. 

Так как проверка через ТС ПИоТ занимает меньшее количество времени, то вы сможете оптимизировать скорость проверки КМ. Однако вы можете также проверять в первую очередь через ОИСМ, а потом в ТС ПИоТ. Параллельные или обратные вызовы увеличивают долю несвоевременных ответов ОИСМ. Последовательная схема — рекомендованный сценарий работы. 

### 4. Устанавливайте контроллер Локального модуля рядом с ЛМ ЧЗ. 

Для корректной работы через локальный модуль контроллер Локального модуля (входит в состав дистрибутива) должен быть установлен на тот же компьютер, где размещён ЛМ ЧЗ. 

- Установка контроллера на отдельной машине нарушает регламент взаимодействия ТС ПИоТ ↔ ЛМ ЧЗ и не поддерживается. 

Проверьте, что на рабочей станции с ЛМ ЧЗ отсутствуют дублирующие процессы контроллера от предыдущих сборок. 

Не меняйте порт обращения к Контроллеру ЛМ ЧЗ в GUI ЕСМ. Порт Контроллера должен несменно занимать порт 50063. 

Также, убедитесь в правильности введённых авторизационных данных ЛМ ЧЗ. В случае, если вы не знаете логин и пароль ЛМ ЧЗ, вы можете выполнить переустановку ЛМ ЧЗ, в следствие которой сможете установить их заново и ввести в интерфейсе ЛМ ЧЗ. Таким образом ЕСМ сможет подключиться к ЛМ ЧЗ и выполнять в том числе и оффлайн проверки. 

### 5. Используйте последние актуальные версии дистрибутивов 

В каждом релизе поддержаны самые последние обновления протокола ЦРПТ и с каждым разом поддержано все больше схем работы и вариантов оптимизации на узле клиента. 

### 6. Не блокируйте адреса ЕСП и ЦРПТ Firewall и другими межсетевыми экранами 

Блокировка сетевых ресурсов может повлечь появление ряда закономерных ошибок, пожалуйста, обеспечьте с узла клиента доступность площадок, указанных в начале инструкции – "Перечень используемых адресов и портов".
