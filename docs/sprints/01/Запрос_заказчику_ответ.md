## 2. Классификация значений: safe / TODO-step2 / TODO-step3

| Значение | Тип | Когда заполнить |
|----------|-----|-----------------|
| `cdn.default_hosts` | Safe (список из методички) | Сейчас |
| `cdn.*` тайминги | Safe | Сейчас |
| `default_timezone=2` | Safe (MVP) | Сейчас |
| `tag1260.foiv_default=030` | Safe (методичка) | Сейчас |
| `tag1260.default` | Safe | Сейчас |
| `tag1260.by_group[*].1263/1264` | **TODO-step2** | После ответа Q1a (норм-акты по группам) |
| `default_timezone` (не-MSK точки) | **TODO-step2** | После ответа Q2a (регионы) |
| `api_key`, `api_key_expires` | **TODO-step3** | После получения из ЛК ЧЗ (Q4a) |
| `lm_chz.login/password` | **TODO-step3** | После развёртывания ЛМ ЧЗ |
| `lm_chz.fn_number` | **TODO-step3** | После получения тестовой ККТ |
| `hosts.test.cdn` | **TODO-step3** | После доступа к sandbox |
| `code_check.batch_size` | Safe 100, но проверить на sandbox (может быть 30) | Step 3 |

**Итого:** без внешних данных разработку **можно начинать** для:
- `MarkingCode::extractCis/decodeMrp` — чистая логика, тесты без внешних зависимостей.
- `CdnService` — на дефолтном списке хостов + circuit breaker.
- `GisMtAuthService` — на чтении из конфига + мок-токен.
- `MarkingCheckService` — с feature-flag `hybrid_check=false` (только онлайн) и mock-респонсами.
- UI кассира, `marking_sell_queue` worker — независимо от внешних данных.

**Блокеры Step 3:**
- `LmChzService` — **нельзя даже начать** без развёрнутого ЛМ ЧЗ (нет endpoint для разработки).
- `Check::addMarkingAttributes` — **нельзя закончить** без официального JSON Атол (Q3).

## 3. Прямые правки SPEC.md под config-first

Заменить разрозненные упоминания значений на ссылки на конфиг:

**§1.2** — `timeZone=2` → `config('marking.default_timezone')`
**§1.3** — добавить явно: `config('marking.api_key')`, `config('marking.api_key_expires')`
**§1.4** — `hosts.test.lm_chz` вместо хардкода `http://127.0.0.1:5995`
**§1.5** — `tag1260.by_group[group_id]`, fallback → `tag1260.default`
**§1.6** — код запрета и `errorCode → level` — вынести в `config('marking.prohibitions')` (см. ниже)
**§1.7** — `batch_size` из конфига
**§3.2** — тайминги CDN из `config('marking.cdn.*')`
**§3.4** — `switch_threshold_sec = config('marking.cdn.switch_threshold_sec')`
**§3.5** — `sell_batch_size` из конфига

**Дополнительно** вынести в конфиг маппинг запретов:

## 4. Development против плейсхолдеров

Чтобы не блокироваться на внешних данных:

**4.1. `MarkingCode` — полностью независим.**

Unit-тесты на фикстурах:
```php
// табак
$km = "00000046233219!SX-RqRADpU7Cev";
assert extractCis($km) === "00000046233219!SX-RqR";
assert decodeMrp($km) === 14630;

// вода (GS-разделитель)
$km = "01048657365749062155esJWe\u001d93dGVz";
assert extractCis($km) === "01048657365749062155esJWe";
```

**4.2. `CdnService` — на fake HTTP.**

```php
// tests/Fake/CdnClient.php — отвечает из фикстур
$client->on('/cdn/info')->reply(['code'=>0,'hosts'=>[['host'=>'https://cdn01.test']]]);
$client->on('/cdn/health/check')->reply(['code'=>0,'avgTimeMs'=>50]);
```

**4.3. `GisMtAuthService` — token из конфига.**

Пока нет sandbox-токена — `MARKING_API_KEY=fake-token` и заглушка `expires_at=2099-01-01`. Все запросы к CDN mock'аются.

**4.4. `LmChzService` — интерфейс + fake.**

```php
interface LmChzClient {
    public function init(array $opts): void;
    public function status(): LmChzStatus;
    public function outCheck(array $cis): OutCheckResult;
    public function sell(array $cis): SellResult;
    public function return(array $cis): ReturnResult;
    public function sold(int $skip, int $limit): SoldResult;
}
// FakeLmChzClient — из фикстур; RealLmChzClient — HTTP.
```

Позволяет разработать `MarkingCheckService` и `CheckService` без живого ЛМ ЧЗ.

**4.5. `Check::addMarkingAttributes` — на плейсхолдере.**

Пока нет официального JSON Атол:

```php
// config/marking.php
'atol' => [
    'tag1260_placeholder' => env('MARKING_ATOL_PLACEHOLDER', true),
],
```

Если `true` — генерируем структуру по §1.5 (ожидаемая), но **не отправляем на реальную ККТ**. В лог — warning «ATOL_JSON_IS_PLACEHOLDER». В prod — `env` заведомо `false`, иначе приложение не стартует.

**Проверка:**
```php
if (!config('marking.atol.tag1260_placeholder') && !file_exists(storage_path('atol_1260_example.json'))) {
    throw new RuntimeException('Official Atol JSON example required for prod');
}
```

## 5. Пять блокеров, которые не закрываются конфигом

| # | Блокер | Почему нельзя заменить плейсхолдером |
|---|--------|--------------------------------------|
| 1 | **Официальный JSON Атол (тег 1260)** | Структура отличается от §1.5; расхождение проявится на ККТ, не в тестах. |
| 2 | **Развёрнутый ЛМ ЧЗ** | Endpoint `/api/v2/*` — локальный; без него `LmChzService` не проверить. |
| 3 | **Sandbox-токен ГИС МТ** | Без него нельзя проверить `/codes/check` на реальных КМ. Mock не покрывает behavior. |
| 4 | **Стек проекта** | Без `composer.json` / `bin/console` / `artisan` невозможно выбрать формат миграций. |
| 5 | **Список регионов (Q2a)** | Если найдётся не-MSK точка — `Cassa::getTimeZone()` перестанет быть заглушкой; критично до релиза. |

Всё остальное (Q1a — норм-акты по группам, Q4a — срок sandbox-токена) — **в конфиг**, дополняется после.

## Резюме

- **Всё внешнее** → `config/marking.php` + `.env`. Один файл правки вместо пересборки.
- **Разработка не блокируется** — 8 из 10 модулей можно писать на mock'ах и фикстурах.
- **Блокируют только**: официальный JSON Атол, живой ЛМ ЧЗ, sandbox-токен, стек, регионы.
- **Расхождения в источниках** (`verified_false` — WARN или BLOCK) — решаются в конфиге, а не в коде.

Готов сразу:
- выдать исправленный `SPEC.md` с ссылками на конфиг вместо хардкода;
- написать `config/marking.php` в виде файла для коммита;
- написать `MarkingCode` + unit-тесты (модуль №1, ни от чего не зависит).
