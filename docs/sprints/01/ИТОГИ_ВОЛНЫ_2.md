## 6. Отклонения от патчей COMMENTS-9 (задокументированы)

1. **Static-состояние mock** → file-backed state (`tests/mock/state.json`).
2. **Маршруты mock** — реальные пути кода, не `/api/v4/true-api/...` + `/api/v2/...` из патча.
3. **`found_false → BLOCK`** применяется только при errorCode 0/null; при 1..11 действует таблица
   SPEC §1.6 (в т.ч. 11 «не найден в трансгране» — WARN, не BLOCK).
4. **Гибрид-онлайн — один кандидат-хост** (быстрый путь); полный failover — в онлайн-только режиме.
   Сбой кандидата фиксируется в `marking_cdn_host_state`.
5. **`Base::$testPdo`** — статический хук вместо DI (модели статические).
6. **DDL ALTER — по `cassa_ord_det`**, не по `order_items` из патча (реальный источник:
   `Models\Order::getByOrderId` → `cassa_ord_det`).
7. **Mock на два порта** (18080/18081) — детерминированные гонки на однопроцессном CLI-сервере.
8. **PDO-SQLite quirks**: лишние именованные параметры в `execute()` ломают SQLite
   («column index out of range») — массивы execute() = точные параметры SQL; литералы —
   однокавычные + `''` (двокавычные в SQLite — идентификаторы).
9. **size-pack** ~190 MiB — легаси-история, не esmpack (см. §5).
10. **`verify_mock.log`** — force-add (паттерн `*.log` в `.gitignore`).
11. **ON DUPLICATE KEY UPDATE не портативен** (COMMENTS-12 2.5) — `INSERT ... ON DUPLICATE KEY UPDATE`
    только MySQL; в `MarkingEmergencyState::activate()` — DELETE+INSERT в транзакции + один повтор
    при UNIQUE-конфликте (`isDuplicateKey()`): портативный эквивалент, SQLite/MySQL.
12. **SQLite: сравнение выражения с bound-параметром** (COMMENTS-12 2.3): в эмулированном PDO SQLite
    `col + 7*86400 < :now` упорядочивается как INTEGER < TEXT (TRUE) — пороги expireIfStale считаются
    в PHP (`col < :staleNow`): сравнение колонки с параметром работает корректно (INTEGER-affinity).
